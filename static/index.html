پنل را به Cloudflare متصل کنید تا یک Worker جدید با ساب‌دامین اختصاصی و KV اختصاصی ساخته شود. پنل مثل یک ریموت، کانفیگ‌ها را به Worker می‌فرستد.
گرفتن توکن
توکن فقط باید دسترسی‌های لازم Worker را داشته باشد: Workers Scripts:Edit، Workers KV Storage:Edit، Workers Routes:Edit، Account Settings:Read، Zone:Read و DNS:Edit. نیازی به Email یا Account ID نیست — Account ID خودکار شناسایی می‌شود.
Worker جدید با نام تصادفی (white-xxxxxx)، ساب‌دامین اختصاصی و KV اختصاصی ساخته می‌شود — نیازی به ورود نام نیست.
